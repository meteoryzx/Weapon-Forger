# 动力设备施工计划

当前检查点：physics-9 已提交为 `87d8882`。physics-9 的偏心锤击仍等待作者体验确认；设备施工可以先进入设计和静态模型阶段，避免把未验收的连续性规则扩散成两套新物理。

## 设备顺序

1. **动力锤**：先实现现有右侧预留设备的可操作切片。第一版只承诺固定上模/下模、工件送进、落锤周期、单次冲击反馈和停止/复位；不加入自动拔长、自动找形或模具长宽比控制。
2. **液压锻压机**：动力锤切片稳定后实现独立设备。第一版承诺闭模、压下速度、最大行程、保压时间、回程和压力反馈；不把每个压力采样转换成独立锤击。

## 共享边界

- 玩家选择工件姿态、送进位置和接触区域；设备只提供其真实的边界和载荷时序。
- 规则层生成可保存的载荷事实，渲染层只显示设备、模具、行程和反馈。
- 两种设备都必须保留材料身份、温度、塑性应变、机械功、损伤、体积和同版本回放。
- 动力锤冲击可以产生瞬时接触事件；液压机必须拥有压下、保压和回程状态，不能伪装成一串点击。

## 动力锤第一切片

输入：送进方向、送进距离、横向位置、冲击频率、启停。

状态：`idle -> lowering -> impact -> rebound -> ready`。每次 `impact` 只提交一次共享接触响应；设备未落到底部时不提交形变，连续运行也要按固定时间步产生可回放的冲击序列。

验收：固定模具接触不穿模；启停和复位可靠；低/高频与轻/重冲击产生可区分的材料事实；工件送进改变受力位置；偏心送进保持当前 physics-9 的截面连续性；体积、温度和回放一致。

## 液压机第一切片

状态：`open -> closing -> pressing -> holding -> opening`。压下受最大行程、最小模具间隙和工件接触约束限制；保压期间记录时间和压力，回程后才提交完整卸载事实。

验收：压下速度和行程可见；保压不会重复产生冲击事件；松开后保留材料历史；无接触时不凭空施压；相同输入回放一致；偏心工件不会被设备模型强行归中。

## 不在第一切片

自动送料、自动转面、模具库存、完整压力场、液压系统故障、弹性回弹求解、宽板翘曲、动力锤音频和最终设备美术。
