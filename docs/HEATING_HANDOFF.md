计划目标：同一工坊右后方，点击送入炉腔持续加热，再次点击抽出判断热色。
实际完成：开放箱式炉腔、前台、三个纵向燃烧管与接地支脚；进出平移，温度/热色/过热提示、共享热历史与炉外冷却。
可用证据：101 项单测、类型检查、Web 与微信构建通过；最终尺度下 17 条浏览器路径整组通过，越桌/半切脚本按缩小后的原料调整并单独复测通过，合计 18 条；实际截图检查通过炉内、炉外与同工坊总览结构。

偏差：scope（作者明确修订）——由局部加热收敛为整体加热；原料与设备按统一尺度缩小。不恢复此前复杂热场。
当前体验精度：risk readability；尺寸、接触、进出和热色必须可读，正式美术精修后置。
延期保留：精细模型、材质、音效、火焰效果；焊合叠层暂缓。

## 行为与因果

玩家可以把一块工件送入或取出炉腔以判断火候，改变共享温度与热历史，供后续锤击读取。

| 环节 | 当前实现与证据 |
| --- | --- |
| 目的 | 获得合适火候，并能抽出观察 |
| 输入 | 点击炉口或钢坯切换进出，底部按钮是等价入口；松手不会停止加热 |
| 约束 | 炉外冷却、长时间高温产生氧化和过热损伤；作者仍需判断节奏是否合适 |
| 信息 | 热色、当前/峰值温度、热暴露、氧化剂量、热损伤与过热提示 |
| 原始状态 | 当前温度、塑性、热历史与损伤由既有热规则更新；不修改几何和质量 |
| 即时反馈 | 钢坯水平平移进出、状态文字切换、温度随时间变化 |
| 对照结果 | 短时加热温度较低；长时更热并有过热风险；抽出后降温 |
| 下游 | 同一会话回总览进入铁砧，保留原工件与温度；核心测试覆盖热状态和确定性回放 |
| 重复决策 | 玩家可以改变停留时间，取出检查后再送回 |

## 实现边界

- 工位模型位于 `src/render/furnace-station-view.ts`，同一场景坐标为右后方 `(380, 0, -300)`；Three.js 的 Y 为上方，炉口朝本地 +Z。
- 选料、切割和加热统一使用 `src/app/workshop-scale.ts` 的 0.46；不缩放单独工件以适配炉口或槽位。其他遗留工序仍有旧比例，后续重构须接入此基准。
- 固定钢料尺寸 336 × 48 × 8 mm，按原料大小安排炉腔和承托台；切割预览、确认与材料共用尺度，90 mm 有限刀路的物理长度不变。
- `move-billet` 在相同位置且经过正时间时可积分，进出本身传零时间。无新增存档字段，保留确定性回放。
- 浏览器只在加热工位前台有焦点时推进热时间。离开工位时取出、保存温度，失焦和隐藏暂停且不追补；并非全局持续冷却。
- 一次操作一块，整件均温；不支持局部热场、深度/旋转影响、多件同时加热、燃料、熔化或真实焊合叠层。
- 归档分支为 `feat/R1-heating-simple`；Git 历史保存本轮实现与测试。DeepSeek 工作区未改动。

## 作者体验清单

准备：打开 `http://127.0.0.1:4182/?accept=heat`，重置当前样本。

1. 看原料、炉口和承托台比例，点击钢坯或炉口一次；钢坯应水平送入，松手后继续加热。
2. 再次点击取出，看热色和温度随炉外停留下降；然后再次送入，较长时间加热，对比火色与过热提示。
3. 点击“工坊总览”，查看加热区在右后、选料区在左后、切割台在左前；从总览点击铁砧可携带当前热工件。

应看到：钢坯不旋转、不变大、不嵌入台面；取出不清零温度，重复送入不换工件。左侧八工序按钮是重置固定样本的验收入口，不是携带工件的移动路径。

作者判断：原料与炉子大小是否合适，镜头是否便于观察，点击切换是否自然，热色和过热是否足以判断火候。

通过标准：自动回归无错误；作者明确确认上述体验。本轮已通过，归档后进入锤击设计，保留先 grill、再参考图、确认后施工的顺序。
