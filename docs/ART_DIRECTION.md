# 工坊美术方向

## 当前制作标准（2026-09-20 作者确认）

2026-09-21 反馈：作者认可新版操作逻辑，但当前灰模式外观尚未验收。简化细节不等于停止美术制作；下一外观迭代应优先改善参考机身的体积/边缘、铸铁与钢/黄铜的材质区分、加工区光影可读性，而不是堆螺栓或转去制作压力机。本次仅调整连击速度与重复更新，没有完成该美术迭代。

目标是形状合理、能支撑操作、美术风格一致的简化模型，不是精确复刻参考图。真实比例与低多边形结构为基础；精细像素质感和 REPLACED 光影仍是后续方向，不作为当前可玩版本的阻塞条件。

- 必须保留：设备可辨识轮廓、合理机械连接、清楚的加工开口、统一工坊材质、正确尺度和可动件层级。
- 可以简化：螺栓数量、隐藏内部、管线、检修附件、倒角和磨损纹理；不设置最低细节数量。
- 不能简化掉：工件真实尺寸、模具对齐、接触与行程、机体/邻站碰撞约束、接触预览及材料响应。视觉简化不授权降低已有力学标准。
- 参考图用来约束造型和风格，不再以像素级轮廓重合分数作为新方案的放行条件。用实际多视角画面、几何测量、运动和操作验证判断；作者外观验收仍未完成。
- 作者再次明确：建模继续使用 img2threejs，不以另一套粗糙手写模型替代。沿用参考分析、规格和生成工厂，按“主体轮廓与比例、可动结构、必要材质与集成”集中推进；降低微细节要求与重复比对次数，不取消建模和风格统一。旧精确复刻流程停在 4/4 的失败记录保留，不改阈值、不改写为通过。

先完成动力锤的简化模型和必要材质统一，再接入已确认的连续锤击操作；可用性验证后再精修。压力机仍排在动力锤之后。

## 已确认共识

- 世界观为早期机械化工坊；设备保持真实比例。动力锤采用早期空气动力锤结构，厚重封闭铸铁机身容纳驱动机构，前方模具工作区向前及两侧敞开。
- 作者喜欢精细像素质感，以《REPLACED》的光影层次、空气感和动作特效作为视觉参考。这是方向参考，不承诺复现其成品质量，也不照搬其题材。
- 三维模型允许简化几何，但工件保留连续形变与足够接触精度。近看可辨像素纹理，整体轮廓保持清楚；界面文字高清，像素效果不能吞掉钢坯厚度、小压痕或模具间隙。
- 操作采用固定主镜头，辅以前视、侧视等检查角度。材料位置和姿态仍可自由调整；检查视角不能成为隐藏错误几何的手段。
- 偏暗室内，侧上方窗光与局部炉火暖光共同形成层次。接触区、冷金属和模具间隙始终可辨认，避免发光过曝。
- 桌面浏览器作为首个质量基准，同时保留移动端和微信端降级路径。阴影、烟尘、反射的实际配置按测量决定，尚未确认最终预算。

## 风格验证与制作顺序

1. 使用 grill-with-docs 对齐未决设计，记录共识和明确暂缓项。
2. 根据新方向制作动力锤提示词与主参考图；作者确认后补三视图和装配细节。
3. 使用 img2threejs 参考分析、规格和生成工厂继续建模，按上述简化标准补主要结构、统一材质，集中验证尺度、运动轴与装配；不追逐旧精确复刻分数。
4. 用动力锤、工件及小范围背景验证静止、连续落锤、移动材料的画面与可读性；这是风格样片，正式游戏仍属于同一连续工坊。
5. 验证空载运动、实际接触与材料响应，再完善事件同步的必要声音和特效。接触反馈不能等同于通用火花爆闪。
6. 作者体验后再将验证过的标准逐步用于其他工位；先动力锤，后压力机。

## 尚未确定

- 像素纹理密度、最终渲染方式、配色和性能预算，需用样片验证。
- 动力锤操作已确认：按住空格连续锤击，松开不发起下一击，已下行的一击完成接触和回程；滚轮调力度，节拍固定；左键拖动平移、右键拖动旋转并选择旋转轴，接触期间受约束。提供与手锤一致的接触区域预览。轴选择控件、深度移动映射与固定节拍数值待实现及样片校准，详见 [POWERED_FORGING_PLAN.md](POWERED_FORGING_PLAN.md)。
- 压力机的实际驱动结构、换头规则和未来焊合边界。持续压载不能替代为连续锤击；多层焊合目前只预留扩展空间。

现有设备模型、参考图和通过的自动测试均不构成本轮美术或基本功能验收。既有共享材料与手锤能力是待核对的复用候选；设备专用实现待对齐后评估保留、重写或删除。
