# 使用可升级的 2.5D 工件几何

工件采用带局部上下表面的平面轮廓，而不是把规则轴向截面或渲染网格当作永久拓扑。这样可以用有限刀路表达任意角度的贯穿切割，并让材料、温度、应力与损伤通过稳定几何单元继续参与锤击、研磨、焊合和热处理；当前只承诺单一外轮廓、开边缺口和局部厚度，不实现封闭孔洞、折叠、扭转、倒扣或完整三维布尔运算。

## Consequences

工位中的移动和旋转只是临时摆放；提交操作时必须把刀路转换到工件局部坐标并记录有限范围。旧规则点阵可以作为首个规则几何实现和迁移来源，但数组位置不再充当持久身份，渲染也不得维护第二套权威几何。封闭孔洞可以在同一平面轮廓模型中后续扩展；真正的三维折叠或扭转需要新的架构决策。
