# 动力锤与液压锻压机采用不同载荷语义

**Status: proposed**

动力锤和液压锻压机都复用工件、模具接触和材料响应，但保留两种不同的载荷时序：动力锤是固定模具下的周期冲击，液压锻压机是有限行程内的压下、保压、回程过程。液压机不能实现为连续调用 `surface-hammer`，否则会丢失保压、行程、接触面积和卸载历史；两种设备也不能用设备外观或预设轮廓替代真实的落点、姿态和支撑事实。

## Considered Options

- **复用表面锤击**：实现快，但把持续压载错误地离散成多次冲击，无法表达保压和卸载。
- **各自独立写形变规则**：短期清晰，但会复制材料历史和体积守恒，后续结果会分叉。
- **共享载荷事实、分离载荷时序**：动力锤和液压机各自生成载荷过程，再交给同一材料/接触响应层；选择此方案以保留统一物理因果。

## Consequences

先制作动力锤真实操作切片，再制作液压机的压下/保压/回程切片。每台设备先完成生图提示词、参考图和 img2threejs 建模，再接入本决策所述载荷和操作反馈。两者需要独立的 `ForgeOperation` 记录和回放测试，并共享模具接触、支撑路径、塑性历史和体积守恒；动力锤体验通过不自动证明液压机可用。
