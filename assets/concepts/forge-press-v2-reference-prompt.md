## 建模边界

- 生图不是工程验证：共享毫米尺度、连续工坊实际空间、模具接触及运动扫掠仍需代码测量。
- 图中先安装平压头；换头接口为后续 V 形等工具保留。V 形工具的具体工作面在规格阶段明确，不能从“V 形”三个字擅自推定焊合力学。当前多层融合尚未实现，不作完成承诺。
- 主体、材质和运动必须达到可体验程度；小螺栓、内部机构和微细磨损可以省略。
- 此文件只提供提示词，尚未生成本轮压力机图片。当前会话无内置生图工具，图像 API 路线待作者确认与本机凭据检查；不得跳过新参考图直接替换压力机。
