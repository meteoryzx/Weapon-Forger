# 动力锤参考图提示词

## 主参考图

为《打了个铁》设计一台早期工业空气动力锤，用于程序化 Three.js 建模参考。真实机械比例，厚重封闭铸铁机身，宽而稳定的落地底座，前部竖直锤杆与导向套，下方厚实砧座。采用自包含空气动力锤的结构语言：后部压气机构和前部工作缸位于机体内，外部呈现可信的检修盖、紧固结构与少量润滑、气路细节。不要用裸露连杆直接驱动锤杆，不混合液压压力机或机械冲床结构。外露传动件有合理支撑与护罩，不剖开主体展示内部。

上下固定平面模具同轴，工作面边缘轻微倒圆，上模抬起，清楚显示装料间隙。加工区向前及左右两侧敞开，后方机身形成有限喉深，不把工件包在箱体中。下模工作面距地 875 mm，能容纳 336 x 48 x 8 mm 标准钢坯送进与转向；主图不放钢坯。其余尺寸是待核定的设计比例，不继承旧占位模型的底座或飞轮尺寸。

完整单设备前侧三分之四视角，轻微俯视，顶部与底座不裁切，中性浅灰背景，均匀工作室光线。清楚展示轮廓、模具间隙、装配和落地关系，不拼接多视图、不画工坊背景。真实比例的简化三维造型与精细像素纹理质感：深灰铸铁、磨亮钢制接触面、少量黄铜润滑件，克制的油污与磨损。像素质感不能吞没薄边、连接关系与模具间隙，不做粗大体素积木。

本图用于核对结构，不使用最终场景的强烈明暗、辉光或烟雾；REPLACED 启发的光影留在后续工坊样片验证。区域预览是游戏运行时反馈，不画在设备参考图中。

## 负面约束

不要现代液压压力机、龙门冲床、裸露液压软管、数控屏幕、科幻装甲、霓虹灯、夸张齿轮装饰、巨大锤头、自动送料、V 形模具、成品轮廓模、用长方形锤面表达长宽塑形选择、错位模具、悬空砧座、断开连接、封闭加工区、人物、工件、文字、尺寸标注、Logo、第二台机器、拼贴、运动模糊、火花、烟雾遮挡、裁切机身。

## 主图确认后的三视图提示词

根据这张已确认的参考图，生成方便三维建模的正交三视图：正视图、右侧视图、后视图。统一比例、基准地面与高度，无透视缩短。严格保持同一台机器的轮廓、部件数量、模具尺寸、检修盖位置与连接关系，不重新设计。清楚展示锤杆导向、上下模具、砧座、底座和加工区喉深。不可见的背面以最少且机械合理的结构补全，补全部分仍需人工核对，不视为已知工程事实。中性背景、均匀照明，不添加无法核实的尺寸数字。

另行生成接触区和导向装配的局部细节图，保持与主图相同结构。主图和三视图冲突时先修正参考。生成图不是机械工程图，实际尺寸、运动轴、行程与间隙在 img2threejs 规格阶段核定。
